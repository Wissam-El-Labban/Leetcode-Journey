Welcome to my leetcode journey, where we demystify the leetcode problems, learn something about data structures and algorithms, and try to make coding interviews a little easier.

We first start by learning important patterns. Patterns are like a tool kit. You read the problem, and understand what kind of patterns apply to it, then reach into our "patter toolkit" and choose the best tool for the job. This is an ideal place to start for a beginner. Missing the crucial step of building your toolbox is why solving so my leetcode problems without a proper understanding of the patterns used to solve them feels like a complete waste of time that just leave you drained with nothing to show for it.
